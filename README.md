# APA Lab - Calculul numerelor prime

Proiect C/OpenMPI pentru calculul numerelor prime din intervalul `[2, n]`.

## Structura

- `sequential/` - implementarea C secvențială;
- `parallel/` - implementarea C paralelă cu OpenMPI;
- `report/` - raportul în limba română, rezultatele și graficele.

## Rulare rapidă

```bash
make
make benchmark
```

Raportul complet este în `report/raport.md`.
